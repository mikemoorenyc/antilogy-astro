## What print size is possible?
Max print size for most prints is 15x18.  There are some oversize options available, but they have limitations.  If you can send a mock-up and dimensions, we can let you know what is possible

## What types of things do you print?
We primarily print wearables.  T-shirts, sweatshirts, etc.  We can also work with totebags and some accessories.  We can do some basic prints on paper as well

## How should files be sent?
Vector files are preferred, with the art sized to how large it will be printed.  Raster images are usable, they need to have been created at 300 DPI at the size you want them to be printed.

## What is turnaround time?
10-15 business days from the time of final order details and a 50% deposit.  Quicker timelines are possible with rush fees.  They are based on how busy we are, so send an email with details ASAP to see what is possible

## How does payment work?
Once we have final order details we'll send you a link with an invoice/payment portal.  50% is needed to start the order.  The other 50% is due before shipping/pick-up
